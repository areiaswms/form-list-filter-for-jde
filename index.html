Privacy Policy - Bulk List Filter for JDE Forms

Last updated: October 9, 2026

Developer: AWS - AREIAS WMS SISTEMAS - areiasaws@gmail.com

What this extension does

Bulk List Filter for JDE Forms lets you paste a list of values into the "in list" filter of the JD Edwards Query Manager so you do not have to type them one by one.

Data we collect

None. The extension does not collect, record, store on any server, share or sell any personal data or browsing data.

Data stored on your device

The extension may save one small setting in your browser's local extension storage: the signature of the "+" button used when you choose "Calibrate +". It stays on your device and is never transmitted.

Values you paste

The values you paste are used only to fill the fields of the page you are working on, inside your browser. They are not sent to the developer or to any third party.

Permissions

  • Access to pages whose address contains "/jde/": needed to read and fill the Query Manager fields.
  • storage: needed to remember the optional calibration setting.

Third-party links

The popup has an optional link to a PayPal donation page. If you click it, PayPal opens in a new tab and PayPal's own privacy policy applies. The extension does not receive or store any payment information.

Changes

If this policy changes, the new version will be published at this same address with a new date.

Política de Privacidade - Bulk List Filter for JDE Forms

Última atualização: 9 de outubro de 2026

Desenvolvedor: AWS - AREIAS WMS SISTEMAS - areiasaws@gmail.com

O que a extensão faz

O Bulk List Filter for JDE Forms permite colar uma lista de valores no filtro "in list" do Query Manager do JD Edwards, para você não precisar digitá-los um por um.

Dados que coletamos

Nenhum. A extensão não coleta, não grava em nenhum servidor, não compartilha e não vende dados pessoais nem dados de navegação.

Dados guardados no seu dispositivo

A extensão pode salvar uma pequena configuração no armazenamento local do seu navegador: a assinatura do botão "+" usada quando você escolhe "Calibrar +". Ela fica no seu dispositivo e nunca é transmitida.

Valores que você cola

Os valores colados são usados somente para preencher os campos da página em que você está trabalhando, dentro do seu navegador. Eles não são enviados ao desenvolvedor nem a terceiros.

Permissões

  • Acesso às páginas cujo endereço contém "/jde/": necessário para ler e preencher os campos do Query Manager.
  • storage: necessário para lembrar a configuração opcional de calibração.

Links de terceiros

O popup tem um link opcional para uma página de doação do PayPal. Se você clicar, o PayPal abre em uma nova aba e a política de privacidade do próprio PayPal se aplica. A extensão não recebe nem guarda dados de pagamento.

Alterações

Se esta política mudar, a nova versão será publicada neste mesmo endereço com a nova data.
